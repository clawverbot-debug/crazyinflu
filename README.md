# crazyinflu: Character Lab (code only)

This public repo holds the code and technical docs only. Research data, character images, videos, music, the posting knowledge pack and all keys are kept out on purpose (see .gitignore).

This is the system behind the Prime Ads AI-character Instagram accounts. It covers:
- finding viral source clips;
- designing characters, with their bios and captions;
- generating videos with Higgsfield, then upscaling them to 4K;
- the dashboard, the radar, and tracking the accounts;
- an API and MCP server for the posting tool.

The live site is https://character-lab-research.netlify.app (Netlify site `character-lab-research`).

## Folder tree

| Folder / file | What it is |
|---|---|
| `dashboard/index.html` | The whole dashboard: Studio (characters, video plans, source clips), Lab (character generator), Radar, Accounts (pool tracking, "What works"). It is plain HTML and JS with no build step. |
| `dashboard/build_data.py` | Rebuilds `dist/data.json` and `dist/characters.json`. It also runs `export_characters.mjs`, which executes the page JS in a VM to export the characters. |
| `dashboard/netlify/functions/` | Serverless functions: `api-v1.mjs` (REST API and MCP server, see `dashboard/API.md`), `radar-*.mjs` (on-demand scraping radar, Apify), `pool-api.mjs` and `pool-daily.mjs` (tracking of our Instagram accounts). |
| `dashboard/netlify/lib/` | Shared code. `radar-core.mjs` holds the hashtags, yield and costs. `knowledge.mjs` is generated from `dashboard/knowledge/POSTING_KNOWLEDGE.md` by `node dashboard/knowledge/build.mjs`. |
| `dashboard/API.md` | API and MCP documentation. |
| `dashboard/knowledge/POSTING_KNOWLEDGE.md` | Everything learned about posting, served at `/api/v1/knowledge`. |
| `lab/` | Character images (GPT Image 2 through kie.ai or fal), profile pictures, and the bio/caption generator `copy_q4.py`. |
| `output/batch1`, `output/batch2` | Video batches: `plan.json` (sources and character), `results.json` (Higgsfield URLs, 480p and 4K), `POSTING.md` kits. |
| `output/compil/` | Compilation of reels with music locked to the dance. `pose.py` uses YOLO pose, then `kine.py` and `tempo3.py`, then `compile3.py`; `evaluate.py` scores the result. |
| `music/` | Song generation with Suno V5 through kie.ai, plus beat and lyric timings. |
| Root scripts | Scrapers and analysis built on Apify: `scrape.py`, `sources_live.py`, `radar.py`, `deep.py`, `scenes.py`, `triage.py`… |
| `analysis/`, `data/`, `pool/`, `radar/`, `discovery/`, `tiktok/` | Research data: scrapes and analysis results, as JSON. |
| `drive_sync.sh` | Copies the deliverables to the shared Google Drive with rclone. |

## Not included in this zip

- **Videos and audio** (`.mp4`, `.wav`, `.mp3`, about 5.8 GB). The final 4K videos are on the Google Drive "INFLU TIB OUTIL EN LIGNE", in `videos/`. The Higgsfield URLs are listed in `output/batch*/results.json`.
- **The original PNG character images** (`lab/gallery`, 775 MB). The HD JPGs the system uses are in `dashboard/img/hd/`.
- **Thumbnails from raw scrapes**, and some raw scrape files that a key scanner flagged as possibly containing tokens. They can be regenerated with the scrapers.
- **`dashboard/dist/`**: generated by `build_data.py`. The clips in it are re-cut by `sources_live.py`.
- **The YOLO model.** Ultralytics downloads it automatically.
- **No keys or secrets.**

## Environment variables (Netlify, names only)

| Variable | Used for |
|---|---|
| `API_KEY` | The API and MCP. Fail-closed: when it is missing, every call answers 503. |
| `RADAR_KEY` | Admin actions on the radar and the account pool (`x-radar-key` header). |
| `APIFY_TOKEN` | Scraping through Apify. Spend guard set to `RADAR_MAX_USD`. |
| `KIE_API_KEY` | Gemini vision for the radar, GPT Image 2 and Suno. |
| `TYPESAFE_API_KEY` | Jev scoring of source clips (shadow mode). |

The local scripts read their keys from files outside the repo, in `~/.config/viral-spy/` and the `.env` of other projects. Ask Thibault; never commit keys.

## Deploy

```bash
cd dashboard && python3 build_data.py && node knowledge/build.mjs
netlify deploy --dir dist --functions netlify/functions --prod --site character-lab-research --no-build
```

The Netlify Blobs stores are `radar`, `pool` and `posts`. Use `consistency: "strong"` for writes; eventual consistency overwrote data before.

## Working together (required once per collaborator)

```bash
sh scripts/install-hooks.sh
```

This turns on the shared git hooks in `.githooks/`. Before every `git commit` and `git push`, they fetch the remote and stop you if teammates pushed commits you don't have yet. The hook then tells you to run `git pull --rebase --autostash` first. Emergency bypass: `SKIP_PULL_CHECK=1 git commit …`.
